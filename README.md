# World of Warcraft Forever

An s&box game set in the world of **World of Warcraft Forever**, built on the
[`wowforever` mount](https://github.com/Exlcior/wowforever-mount), which reads the game from the player's own
installation. This repository contains no game data.

Play as your own WoW character in the open world: character creation (race, appearance, equipment), walking,
running, jumping, swimming, ghost state, spells, mounts and free flight. NPCs and creatures appear around the
player; F9 opens the menu (destinations, character, spells, mount, flight). The world streams around the player
with its sky and lighting.

## Getting started

1. Install the mount (see its README). It needs your own World of Warcraft Forever installation.
2. Open `world_of_warcraft_forever.sbproj` in s&box and play `scenes/exploration.scene`.

Controls: WASD/ZQSD and mouse, Shift to walk, Space to jump, Ctrl to crouch, R to change view, F9 for the menu.

See [docs/architecture.md](docs/architecture.md) and [docs/current-state.md](docs/current-state.md).
